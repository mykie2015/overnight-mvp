# Intent: Customer Support Agent ## Objective Help customers resolve Tier-1 technical issues without frustration so they can get back to work quickly and maintain trust in our product. ## Desired Outcomes - Customer confirms their issue is resolved - No follow-up ticket within 24 hours - Customer rates interaction as helpful (>4/5) ## Constraints ### Steering Constraints - Prioritize clarity over technical accuracy - Use simple language, avoid jargon - Acknowledge frustration empathetically ### Hard Constraints - Never access customer payment information - Maximum 3 knowledge base API calls per ticket - Response time must be <2 seconds ## Decision Types & Autonomy ### Autonomous Decisions - Standard troubleshooting steps - Providing documentation links ### Escalate to Human - Refund requests >$50 - Account security issues - Unable to resolve after 3 attempts ## Stop Rules - Complete: Customer confirms resolved - Escalate: Unable to resolve after 3 attempts - Halt: Security violation detected

⚡ Output: LangChain Agent

class CustomerSupportAgent: """Agent with embedded intent guardrails.""" def __init__(self): self.llm = ChatAnthropic( model="claude-sonnet-4-5-20250929", temperature=0 ) # Intent-based constraints self.steering_constraints = [ "Prioritize clarity over technical accuracy", "Use simple language, avoid jargon", "Acknowledge frustration empathetically" ] self.hard_constraints = [ "Never access customer payment information", "Maximum 3 knowledge base API calls", "Response time must be <2 seconds" ] self.autonomous_decisions = [ "Standard troubleshooting steps", "Providing documentation links" ] self.escalation_triggers = [ "Refund requests >$50", "Account security issues", "Unable to resolve after 3 attempts" ] self.agent = self._build_agent() def run(self, input_text: str) -> Dict: # Check escalation triggers for trigger in self.escalation_triggers: if trigger.lower() in input_text.lower(): return { "status": "escalate", "reason": f"Trigger: {trigger}" } # Run agent with guardrails result = self.agent.invoke({"input": input_text}) return { "output": result["output"], "status": "complete" }

🎯 What Gets Embedded

Objective-Aware Prompts

Agent understands WHY it exists, not just WHAT to do. Guides decision-making in edge cases.

Steering Constraints

Soft boundaries in prompt layer guide agent thinking and trade-offs.

Hard Constraints

Non-negotiable boundaries enforced in code, not prompts. Cannot be bypassed.

Decision Boundaries

Clear separation: autonomous decisions vs escalation triggers. No ambiguity.

Stop Rules

Complete/escalate/halt conditions prevent runaway behavior and infinite loops.

Health Metrics

Non-regression constraints prevent optimization shortcuts and quality degradation.
